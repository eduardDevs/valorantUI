# ValorantUI

**ValorantUI** is a SwiftUI-based application that leverages the Valorant API to display detailed information about the game, including agents, maps, weapons, and more. It features a clean, modern interface designed to provide an intuitive and visually appealing experience for Valorant fans.

## ✨ Features

- 📋 Full list of agents with abilities and descriptions
- 🗺️ Map details and key locations
- 🔫 Weapon stats, categories, damage, and more
- 🏆 Favorites system to save your top picks
- 🔍 Fast and responsive search functionality
- 🎨 100% SwiftUI interface

## 🚀 Built With

- [SwiftUI](https://developer.apple.com/xcode/swiftui/) – Apple's declarative UI framework
- [Valorant API](https://valorant-api.com/) – Free API for accessing game data

## 🧱 Project Structure

This project follows the **MVVM (Model-View-ViewModel)** architectural pattern to ensure scalability and maintainability.
